# Rise & Purl: the class example run

Roll: Wholesome · Sourdough Starter · Meal Kit · Competitive Knitters. Brand line: “A sourdough starter that rises while you knit.”

Each prompt below is exactly what went to Gemini, built by the app. The sketches were drawn for the test run. Each practice ran in a new Gemini chat.

## B · Logo

In: Image 1: `2-logo-sketch.jpg`  
Out: `3-logo.jpg`

```
Image 1 is my logo sketch. Use its shapes and layout. Make a combination logo for “Rise & Purl”. Lettering: bold geometric sans. 1-bit: solid black on pure white. No gray, no gradients, no shading, no 3D. Flat vector, thick black outlines. Centered on a plain white square.
```

## C · Product

In: Image 1: `1-product-sketch.jpg` · Image 2: `3-logo.jpg`  
Out: `4-product-turnaround.jpg`

```
Image 1 is my product sketch. Make a product turnaround of a sourdough starter jar: frosted glass and oiled walnut with a embossed finish. Image 2 is my logo. Print it on the sourdough starter jar exactly as shown. One sheet, four matching views in a 2x2 grid: front, side, three-quarter, top-down. Same product, same materials in every view. Only the camera moves. Pure white background. Soft studio lighting. Subject only. No people, no actions, no location.
```

## D · Setting

In: Image 1: `4-product-turnaround.jpg`  
Out: `5-setting.jpg`

```
Image 1 is my product. Keep it exactly as shown. A knitter feeds it flour between rows in a sunny yarn shop today, crisp morning air. Don't change the product's materials, colors, or label.
```

## G · Final ad

In: Image 1: `3-logo.jpg` · Image 2: `5-setting.jpg` · Image 3: `6-layout.png` (drawn in the app, Practice F)  
Out: `7-final-ad-risograph.jpg`

```
Aspect ratio 4:5. A portrait poster ad for “Rise & Purl”.
Image 1 is my logo. Image 2 is my product in its setting. Image 3 is my layout.
Subject: The sourdough starter jar from image 2 and the logo from image 1, exactly as shown.
Setting: A knitter feeds it flour between rows in a sunny yarn shop today, crisp morning air.
Structure: Follow the layout in image 3. Use it for placement only. Don't draw its boxes or labels. Logo, small, in the top-left corner. Headline across the top. Product, large, across the bottom two-thirds. Leave the top-right corner completely empty. Headline text: “Rise to the occasion”.
Style: Risograph print. Playful mood, fluorescent pink and teal palette, flat even lighting.
```
